# Source documents

The PDFs are not included in this repository. Download them into this folder before running the notebook.
Use the exact file names below so the notebook finds them (it reads every `*.pdf` in this folder).

| File | Source | Notes |
|---|---|---|
| `NIST.AI.100-1.pdf` | NIST AI Risk Management Framework (AI RMF 1.0), from nist.gov | US government publication |
| `owasp-top-10.pdf` | OWASP Top 10 (2021), from owasp.org | Open license; check the OWASP site for terms |
| `RP-008344-DS-5-raspberry-pi-4-product-brief.pdf` | Raspberry Pi 4 Model B product brief, from raspberrypi.com | Copyrighted; download it yourself rather than redistributing |

You can use any PDFs. The pipeline is not tied to these three.
